# Phase 25, Plan 1: CI & Artifact Cleanup

## Goal
Close the four remaining gaps under R25-CI / R25-DOC.

## Context
- **R25-CI.1 is already satisfied**: `.github/workflows/ci.yml` runs `bun run check` (lint+typecheck) and `bun run test` on every push/PR to `main`. No new workflow needed for this one — just confirm it in the summary.
- **R25-CI.2 is not satisfied**: `packages/ci`'s own composite action (`packages/ci/action.yml`, built in Phase 6) is never used in this repo's own `.github/workflows/`. It requires an `anthropic-api-key` input (`required: true`). Checked `gh secret list -R draht-dev/draht`: **no secrets are currently configured on this repo** — so the new workflow must not hard-fail every PR the moment it merges. Guard the job with `if: ${{ secrets.ANTHROPIC_API_KEY != '' }}` (job-level, not step-level) so it's a graceful no-op until Oskar adds the secret, and say so explicitly in the workflow file's comments and in the phase summary.
- **R25-DOC.1**: `.planning/phases/{14,15,16,17,18}-phase-*/​*-SUMMARY.md` (11 files total) are literal unfilled templates — every one has `[task]`, `[hash]`, `[files]`, `[results]`, `[deviations, decisions]` placeholder text, all bulk-stamped with an identical per-phase timestamp (e.g. all 3 Phase 14 files say exactly `2026-02-28 19:58:36`) from a prior mechanical backfill that created the files but never filled them in. Reconstruct real content from `git log` around each phase's timestamp window:
  - Phase 14 (TDD-First Core): ~2026-02-28 19:58
  - Phase 15 (DDD-First Core): ~2026-02-28 20:04
  - Phase 16 (Invoice Generator, touches `packages/invoice/`): ~2026-02-28 20:06
  - Phase 17 (Compliance Checker, touches `packages/compliance/`): ~2026-02-28 20:08
  - Phase 18 (draht.dev Website Content): ~2026-02-28 20:11
  Use `git log --oneline --before=<window-end> --after=<window-start>` and match commits to each phase's ROADMAP goal/requirements to figure out which commits belong to which plan file.
- **R25-DOC.2**: `packages/draht-claude/hooks/hooks.json` and `packages/draht-codex/hooks/hooks.json` are 50 lines each, identical except 4 lines where draht-codex uses `${PLUGIN_ROOT:-${CLAUDE_PLUGIN_ROOT}}` and draht-claude uses plain `${CLAUDE_PLUGIN_ROOT}`. The repo already has an established pattern for this exact problem — `scripts/sync-draht-tools.mjs` (checked via `node scripts/sync-draht-tools.mjs --check`, wired into the root `npm run check` pipeline as `check:draht-tools`) keeps `draht-tools.cjs` in sync across consumers from one canonical source. Follow the same pattern for hooks.json.
