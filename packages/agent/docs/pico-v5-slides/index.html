Task kinds replace the fixed graph

type GenerationState =
  | { phase: "prepare" }
  | { phase: "requesting"; attempt: number; cutoff: Id }
  | { phase: "retrying"; attempt: number; retryAt: number }
  | { phase: "deferred"; handle: DeferredHandle };

const Generation =
  defineTask<null, GenerationState, { entryId: Id }>({

    phases: { prepare, requesting, retrying, deferred }, // supplied handlers

  });

Core scheduler knows tasks. Each kind knows its own phases.

Abort is durable and semantic

conversation C
├─ generation G7 ──owns──→ sub-conversation D ── tool T9
└─ background job J8                         survives ordinary abort

1  commit abortRequested on selected non-background tasks/subtree
2  signal and join each active run invocation
3  scheduler starts fresh abort invocations
4  abort handlers commit terminal outcomes + retire task documents

crash anywhere → durable marks remain → reopen continues abort

Clients observe committed consequences; process-local abort signals are not replicated state.

Close is not abort

OperationDurable writesDistribution and reopen
Cancel a ContextNone by itselfRequests cancellation of one call/wait; remote propagation depends on transport. Committed work is not undone.
Abort task/conversationAbort marks, then terminal outcomesTraverses ownership; reopen finishes marked aborts.
Close SessionNo abort/terminal writes caused by closeAdmitted commits may settle; then join, stop watches, close storage, and withdraw services. Reopen resumes checkpoints.

Disconnecting a client does not silently abort shared work.

Storage is one contract, two products

SQLite

  • reclaim after committed base/retirement

The deliberate sharp edges

Ownership

  • draft/proxy escape
  • inserted and duplicated aliases
  • table read after table write
  • large values in terminal task records

Liveness

  • external or nested waits on the line
  • get-or-create “reads”
  • unstarted watch buffering
  • checkpoint starvation
  • continuing after storage failure

Stable definition IDs, mounted paths, and fork settings are persisted protocol.

Footguns: drafts have one owner

let escaped: CanvasState | undefined;
await session.commit(async tx => {
  const canvas = await tx.doc(CanvasDoc, { scope: "session" });
  const stroke: Stroke = { color: "black", points: [] };
  canvas.strokes.push(stroke);
  stroke.points.push(point);       // wrong: draft owns stroke now
  escaped = canvas;
}, context);
escaped!.strokes.push(otherStroke); // wrong: transaction ended

const sharedStroke: Stroke = { color: "red", points: [] };
await session.commit(async tx => {
  const canvas = await tx.doc(CanvasDoc, { scope: "session" });
  canvas.strokes.push(sharedStroke, sharedStroke); // wrong: duplicated alias
}, context);

Do not retain drafts, nested proxies, bound methods, or assigned mutable aliases.

Footguns: do not block or outrun the line

// Independent mistake 1: external effect on the Session line.
await session.commit(async _tx => requestModel(context), context);

// Independent mistake 2: nested line operation.
await session.commit(async _tx =>
  session.commit(async _inner => {}, context), context);

// Independent mistake 3: table read after table write.
await session.commit(async tx => {
  tx.appendEntry(conversationId, entry);
  await tx.entry(otherId);
}, context);

await session.snapshot(Doc, target, context); // may create + commit

// never start()/stop(): buffered commits are unbounded
checkpointWhen: () => false // replay/storage can grow while live
