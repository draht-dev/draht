# @draht/install

Draht unified installer engine. Ships the `draht-install` (machine-level component management: `plan`, `install`, `status`, `doctor`, `update`, `uninstall`) and `draht-init` (project bootstrap) bins over transactional, hash-manifested state in `~/.draht/install/`.

Documentation lands with the implementation phases; see `.planning/specs/2026-08-12-unified-distribution-product.md` in the repository.
